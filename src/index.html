BrowserVec

Text and image semantic search running entirely in-browser. Custom C++ nearest-neighbor engine (HNSW and product quantization) compiled to WebAssembly, with multi-threaded search. 0.98 recall@10 on 1M vectors, matching native hnswlib. Runs 4–7× faster than hnswlib in-browser. Scales to over 65k QPS on 10 threads.

ProofNet

Decentralized anonymous network enforcing bandwidth fairness while preserving privacy. Uses onion routing with signed forwarding receipts that are verified before sends are authorized. Dockerized adversarial harness inserts malicious nodes (forged signatures, forged receipts, replayed IDs) which the protocol detects and blocks.
